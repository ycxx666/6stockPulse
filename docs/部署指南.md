# 6stockPulse · 部署指南

## 环境要求

| 组件 | 版本 | 备注 |
|------|------|------|
| Python | 3.10+ | 推荐 3.11 |
| PostgreSQL | 14+ | 16+ 推荐 (支持更多特性) |
| RAM | 1GB+ | 视爬虫频率 |
| CPU | 2+ cores | aiohttp 异步 |
| Disk | 5GB+ | 数据 + 日志 |

## 1. macOS / Linux 部署

### 1.1 启动 PostgreSQL
```bash
# macOS Homebrew
brew install postgresql@16
brew services start postgresql@16
echo 'export PATH="/opt/homebrew/opt/postgresql@16/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# Linux (Ubuntu)
sudo apt-get install postgresql-16
sudo systemctl start postgresql
```

### 1.2 创建数据库
```bash
sudo -u postgres psql -c "CREATE USER pulse WITH PASSWORD 'pulse123' SUPERUSER;"
sudo -u postgres psql -c "CREATE DATABASE stockpulse OWNER pulse;"
# 或 (macOS 本地)
psql -U davi60 -h /tmp postgres -c "CREATE DATABASE stockpulse;"
```

### 1.3 初始化 schema
```bash
cd 6stockPulse
psql -U pulse -h localhost stockpulse -f db/schema.sql
```

### 1.4 安装依赖
```bash
pip3 install -r requirements.txt
```

`requirements.txt`:
```
asyncpg>=0.29
fastapi>=0.110
uvicorn[standard]>=0.27
websockets>=12
aiohttp>=3.9
apscheduler>=3.10
pydantic>=2.5
```

### 1.5 启动
```bash
python3 main.py --port 8902
```

## 2. 生产部署 (Gunicorn + Systemd)

### 2.1 Gunicorn 启动
```bash
pip3 install gunicorn
gunicorn api.server:app \
  -w 4 \
  -k uvicorn.workers.UvicornWorker \
  -b 0.0.0.0:8902 \
  --timeout 60 \
  --access-logfile logs/access.log
```

### 2.2 Systemd Service
`/etc/systemd/system/6stockpulse.service`:
```ini
[Unit]
Description=6stockPulse Data Service
After=network.target postgresql.service

[Service]
Type=simple
User=stockpulse
WorkingDirectory=/opt/6stockPulse
ExecStart=/usr/bin/python3 main.py --port 8902
Restart=always
RestartSec=10
Environment=PG_HOST=localhost
Environment=PG_USER=pulse
Environment=PG_PASSWORD=pulse123

[Install]
WantedBy=multi-user.target
```

启动:
```bash
sudo systemctl daemon-reload
sudo systemctl enable 6stockpulse
sudo systemctl start 6stockpulse
sudo systemctl status 6stockpulse
```

## 3. Docker 部署

### 3.1 Dockerfile
```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8902
CMD ["python3", "main.py", "--port", "8902", "--host", "0.0.0.0"]
```

### 3.2 docker-compose.yml
```yaml
version: '3.8'
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_USER: pulse
      POSTGRES_PASSWORD: pulse123
      POSTGRES_DB: stockpulse
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./db/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
    ports:
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U pulse"]
      interval: 5s

  app:
    build: .
    depends_on:
      postgres:
        condition: service_healthy
    environment:
      PG_HOST: postgres
      PG_USER: pulse
      PG_PASSWORD: pulse123
      PG_DATABASE: stockpulse
    ports:
      - "8902:8902"
    restart: unless-stopped

volumes:
  pgdata:
```

启动:
```bash
docker-compose up -d
```

## 4. Nginx 反向代理

```nginx
server {
    listen 80;
    server_name stockpulse.example.com;

    # HTTP
    location / {
        proxy_pass http://127.0.0.1:8902;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket
    location /ws/ {
        proxy_pass http://127.0.0.1:8902;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }
}
```

## 6. 备份策略

### 6.1 DB 备份
```bash
# 每日 0 点
pg_dump -U pulse -h localhost stockpulse | gzip > backup-$(date +%Y%m%d).sql.gz

# 恢复
gunzip < backup-20260713.sql.gz | psql -U pulse stockpulse
```

### 6.2 数据保留
- `news`: 7 天
- `stock_prices`: 90 天
- `stock_announcements`: 永久
- 清理: 由 APScheduler 自动执行

## 7. 性能调优

### 7.1 PostgreSQL
```ini
# postgresql.conf
shared_buffers = 256MB
effective_cache_size = 1GB
work_mem = 16MB
max_connections = 100
```

### 7.2 爬虫间隔
- 行情: 3-5s
- 资金流: 60s (交易时段)
- 新闻: 60s

### 7.3 WS 推送
- 实时行情 WS: 单次推送 ≤ 50 条
- 推送频率: 3-10s
