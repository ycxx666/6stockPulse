# 演示视频脚本（≤5 分钟）

> 格式：MP4，时长 ≤5 分钟，文件 ≤500MB；录屏展示核心功能、操作流程、应用效果，画面清晰、音频流畅，重点突出创新亮点。
> 建议：录屏 + 旁白；先录屏再配旁白，或边操作边讲解。以下按 5 分钟（300 秒）编排。

---

## 分镜脚本

| 时间段 | 画面 | 解说词（旁白） | 要点 |
|---|---|---|---|
| 0:00–0:20 | 打开智能体对话界面，展示作品名称与赛道标签 | “大家好，我们带来的作品是《StockPulse 全球量化资讯与智能研判智能体》，属于‘科学研究和学科建设’赛道。它要解决的，是金融科研中‘海量数据难采集、难研判’的问题。” | 一句话定位 + 赛道 |
| 0:20–0:55 | 提问“今天 A 股市场情绪怎么样”，展示回答 | “我们先看市场情绪。智能体调用了情绪工具，给出 A 股情绪分，并把每个因子的贡献一一列出——市场宽度、涨跌停强度、量能、主力资金……每个分数都能追到具体数据。” | 场景 1：情绪 + **因子可解释** |
| 0:55–1:25 | 提问“哪些板块在涨、资金流向哪里”，展示回答 | “再看市场宽度和板块。它展示了涨跌家数、涨停跌停，以及概念和行业板块的资金流向和领涨板块，帮助我们快速把握资金主线。” | 场景 2：宽度 + 板块资金流 |
| 1:25–1:55 | 提问“当前有哪些机会和风险”，展示回答 | “这是机会与风险信号。每一条信号都带有证据链和置信度——比如某板块资金净流入、量能放大，形成一条机会信号。” | 场景 3：信号 + **证据链** |
| 1:55–2:25 | 提问“预测明天大盘涨还是跌”，展示回答 | “再看次日方向研判。它给出涨、平、跌三档概率和置信度，并说明依据的六个因子。注意它明确写了‘仅供科研教学参考，不构成投资建议’。” | 场景 4：预测 + **概率≠确定性 + 免责** |
| 2:25–2:50 | 提问“看看贵州茅台 600519”，展示回答 | “个股查询也很直接，输入代码就能得到实时行情、分时和日 K 概览以及所属板块。” | 场景 5：个股概览 |
| 2:50–3:35 | 回放/放大因子表、证据链、免责声明 | “到这里，作品的三个创新点已经体现出来了：第一，可解释——每个结论都能追到因子和证据；第二，数据事实与模型研判分离——大模型只负责解释，不直接预测，降低幻觉；第三，实时数据——回答基于当日真实行情，而不是静态资料。” | **创新亮点重点呈现** |
| 3:35–4:10 | 演示稳健性：数据缺失提示 / 越界提问拒绝 | “我们还特别关注稳健性。非交易时段它会明确提示数据未更新而不是编造；当你问‘买哪只股票能赚钱’时，它会拒绝给建议并给出免责声明。” | 稳健性 + 合规 |
| 4:10–4:45 | 回到作品首页/架构示意 | “对学校而言，它既是科研数据底座，也可以作为金融、数据科学等学科的教学实训平台，让学生对照因子和权重，理解量化分析是怎么做的。这正是‘科学研究与学科建设’赛道的价值所在。” | 学科建设价值 |
| 4:45–5:00 | 结束画面：作品名 + 团队信息 | “谢谢大家，欢迎各位评委老师指导。” | 收尾 |

## 录屏与制作要点

- [ ] 提前清空聊天记录，保证每个场景从干净界面开始，避免历史对话干扰
- [ ] 打开智能体的“工具调用/思考过程”开关（若平台支持），用于体现“先取数、再作答”的流程
- [ ] 每个场景只问一个问题，回答完整展示 3-5 秒后再切下一场景
- [ ] 关键数据（因子表、证据链、概率、免责声明）给 2 秒放大特写
- [ ] 旁白语速适中（约每分钟 200-220 字），控制在 5 分钟内
- [ ] 导出 MP4 时确认时长 ≤5 分钟、文件 ≤500MB（1080p 通常远小于上限）
- [ ] 检查音频无杂音、画面无裁切，重点突出创新亮点（可解释性 / 人机分工 / 实时数据 / 学科建设价值）

## 剪辑分工建议

- 前 2:50 用五个场景串起“功能演示”，后 2:10 用“亮点回放 + 稳健性 + 价值总结”，避免头重脚轻。
- 若总时长超 5 分钟，优先压缩 3:35–4:10 的稳健性段落（可只保留“越界拒绝”一个例子）。
