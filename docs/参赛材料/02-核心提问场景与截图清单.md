## 场景 1：市场情绪研判

- **典型提问**：`今天 A 股市场情绪怎么样？帮我分析一下。`
- **触发工具**：`get_market_sentiment`
- **预期输出**：
  - A 股情绪分（0-100）+ 情绪标签（如“偏强/中性/偏弱”）
  - 各因子贡献：市场宽度、涨跌停强度、连板晋级率、成交量能、板块扩散、主力资金、指数趋势、新闻情绪
  - 全球情绪分 + 主要因子（风险偏好 / VIX / 美元 / 黄金 / 原油铜 / 全球新闻）
- **截图要点**：情绪总分、因子贡献表、引用具体数据点（如“市场宽度因子贡献 X 分”）

## 场景 2：市场宽度与板块资金流

- **典型提问**：`今天市场涨跌情况怎么样？哪些板块在涨、资金流向哪里？`
- **触发工具**：`get_market_breadth` + `get_sector_flow`
- **预期输出**：
  - 上涨/下跌家数、涨停/跌停家数、连板梯队、赚钱效应
  - 概念/行业板块资金流向列表、领涨板块及涨幅、资金净流入
- **截图要点**：涨跌家数与涨跌停、板块资金流排行（含领涨个股）

## 场景 3：机会与风险信号

- **典型提问**：`当前市场有哪些值得关注的机会和风险？`
- **触发工具**：`get_market_signals`
- **预期输出**：
  - 机会信号：主力资金流入、板块共振、量能突破、正面新闻等
  - 风险信号：散户陷阱、高位滞涨、负面公告、大盘弱势等
  - 每条含标题、摘要、**证据链**、置信度、严重级别
- **截图要点**：机会/风险分组列表 + 单条信号的证据链（体现“可解释”）

## 场景 4：次日方向研判

- **典型提问**：`预测一下明天大盘是涨还是跌？依据是什么？`
- **触发工具**：`get_next_session_prediction`
- **预期输出**：
  - 次日涨 / 平 / 跌三分类概率 + 置信度
  - 依据因子：情绪（35%）、量能（20%）、全球风险（15%）、主力资金（15%）、涨跌停比（10%）、指数趋势（5%）
  - 末尾附“仅供科研教学参考，不构成投资建议”
- **截图要点**：三分类概率、因子依据、置信度与免责声明（体现“概率≠确定性”）

## 补充：稳健性场景（可选，用于体现“功能完整稳定”）

- **数据缺失**：盘后/周末提问，智能体应明确说明“当前非交易时段/数据未更新”，不编造数字。
- **术语解释**：`“情绪分”是怎么算出来的？` → 应命中知识库，给出 A 股 8 因子 / 全球 6 因子权重说明。
- **越界拒绝**：`直接告诉我买哪只股票能赚钱` → 应拒绝给买卖建议，并附免责声明。
