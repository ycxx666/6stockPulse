# 指标方法论

本知识库说明 StockPulse 各类指标的计算口径。

## 一、A 股情绪分（0-100，多因子加权）

| 因子 | 权重 | 计算口径 |
|---|---|---|
| 市场宽度 | 15% | 上涨家数 / 总家数 × 100 |
| 涨跌停强度 | 15% | 涨停家数 / 总家数 × 500（2% 映射 10 分） |
| 连板晋级率 | 15% | 连板梯队结构得分 |
| 成交量能 | 15% | 量能比偏离 1.0 的程度 |
| 板块扩散 | 15% | 上涨板块 / 总板块 × 100 |
| 主力资金 | 10% | 主力净流入（亿元）分档：>100 亿=85，>30 亿=70，>0=55，>-30=40，否则 20 |
| 指数趋势 | 8% | 上证 5 日 vs 20 日均线偏离 |
| 新闻情绪 | 7% | 近 2 小时新闻平均情感 |

所有因子保留 raw、normalized、weight，写入 sentiment_snapshot 表，可逐项溯源。

## 二、全球情绪分（0-100，多因子加权）

| 因子 | 权重 |
|---|---|
| 股票指数风险偏好 | 25% |
| VIX 反向分 | 20% |
| 美元强弱反向 | 15% |
| 黄金避险反向 | 10% |
| 原油/铜增长预期 | 10% |
| 全球新闻情绪 | 20% |

## 三、次日方向预测（规则基线 rule-baseline-v1）

| 因子 | 权重 |
|---|---|
| A股情绪分 | 35% |
| 量能比 | 20% |
| 全球风险偏好 | 15% |
| 主力资金方向 | 15% |
| 涨跌停比 | 10% |
| 指数趋势 | 5% |

所有因子先归一化到 0-1（高分=偏涨），加权后映射为涨/平/跌三分类概率，并给出置信度与因子解释。LLM 只负责解释结果，不直接预测。

## 四、信号引擎规则

- **机会信号**：主力资金连续流入、板块共振、量能突破、正面新闻。
- **风险信号**：负面公告（减持/立案等）、高位滞涨、散户陷阱、大盘弱势。
- 每条信号包含标题、摘要、证据链、方向、置信度、严重级别。
