# 量化术语表

本知识库用于统一 StockPulse 金融量化研究助手的术语口径。

## 情绪与市场结构

- **情绪分（0-100）**：衡量市场多空强弱的综合评分，高于 60 偏强、40-60 中性、低于 40 偏弱。
- **市场宽度**：全市场上涨/下跌/平盘家数及占比，反映涨跌结构，是情绪的核心因子。
- **涨跌停强度**：涨停/跌停家数及其占比，体现赚钱效应与极端情绪。
- **连板梯队**：连续涨停的股票按板数分层（2板/3板/4板/5板+），反映短线接力情绪。
- **赚钱效应**：涨停股的封板率、次日溢价等，衡量打板/短线资金的实际收益。
- **量能比**：当日成交量（额）与昨日同期或均值的比值，>1.2 为放量、<0.8 为缩量。
- **板块扩散**：上涨板块数量占比，衡量热点是集中还是扩散。
- **主力资金**：大单/超大单净流入金额（元），正为流入、负为流出。
- **风险偏好**：资金愿意承担风险的倾向，通常用股指、VIX、汇率、黄金等综合衡量。
- **VIX**：波动率指数，越高代表市场恐慌、风险偏好越低（反向因子）。
- **板块资金流**：概念/行业板块的主力净流入、涨跌幅、换手率等。

## 信号与预测

- **机会信号（opportunity）**：资金流入、板块共振、量能突破、正面新闻等偏多线索。
- **风险信号（risk）**：减持公告、高位滞涨、散户陷阱、大盘弱势等偏空线索。
- **证据链（evidence）**：每条信号附带的数据依据，如公告、新闻情绪、资金流数值。
- **置信度（confidence）**：0-1，表示该结论的可信程度，不等于发生概率。
- **严重级别（severity）**：info（提示）/ warning（警告）/ critical（严重）。
- **次日预测**：基于规则基线给出下一交易日涨/平/跌三分类概率与置信度。
- **概率 ≠ 确定性**：概率是模型在给定因子下的倾向，不代表必然发生。
