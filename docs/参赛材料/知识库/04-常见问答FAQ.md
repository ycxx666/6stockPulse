# 常见问答 FAQ

**Q：情绪分是怎么算出来的？**
A：A 股情绪分由 8 个因子加权：市场宽度 15%、涨跌停强度 15%、连板晋级率 15%、成交量能 15%、板块扩散 15%、主力资金 10%、指数趋势 8%、新闻情绪 7%。每个因子保留原始值和权重，可逐项溯源。

**Q：次日预测靠谱吗？**
A：预测采用规则基线模型（情绪 35% + 量能 20% + 全球风险 15% + 主力资金 15% + 涨跌停比 10% + 指数趋势 5%），给出涨/平/跌三分类概率与置信度。概率不等于确定性，请结合置信度理解。

**Q：数据多久更新一次？**
A：行情约 3-60 秒、市场宽度约 30 秒、情绪约 60 秒、信号约 300 秒、板块资金流约 120 秒；预测在 11:30 和 15:00 生成。

**Q：为什么数据是空的或默认值？**
A：非交易时段（盘前、盘后、周末、节假日）行情不更新，情绪分可能显示默认 50 分。请在交易日 9:30-15:00 查询。

**Q：能推荐股票或给买卖建议吗？**
A：不能。本助手只做数据分析和研判展示，不提供投资建议，所有内容仅供科研教学参考。

**Q：支持哪些查询？**
A：市场情绪、市场宽度、机会/风险信号、次日方向研判、板块资金流、个股概览。

**Q：置信度和概率有什么区别？**
A：概率是"涨/平/跌"三分类各自的可能性；置信度表示模型对本次判断的整体把握程度。两者都需结合因子解读。
