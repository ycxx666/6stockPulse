## 二、作品功能简介与拟解决的核心问题

### 2.1 功能简介

StockPulse 是一个面向高校科研与教学的金融量化研究智能体。它以“多源实时采集 — 可解释量化建模 — 大模型智能研判 — 实时可视化”为主线，将分散的行情、资金、板块、新闻等异构数据汇聚为可解释的量化研判结论，并通过自然语言对话对外提供服务。

智能体主要提供五类能力：

1. **市场情绪研判**：输出 A 股与全球市场情绪分（0-100），并解释各因子的原始值、归一化值与权重贡献；
2. **市场宽度与板块分析**：展示涨跌家数、涨跌停、连板梯队、赚钱效应，以及概念/行业板块资金流向与领涨板块；
3. **机会与风险信号**：输出结构化的机会（资金流入、板块共振、量能突破、正面新闻）与风险（散户陷阱、高位滞涨、负面公告、大盘弱势）信号，每条附证据链与置信度；
4. **次日方向研判**：给出次日大盘涨/平/跌三分类概率与置信度，并说明依据因子；
5. **个股概览与资讯**：查询单只股票实时行情、分时/日 K 概览与所属板块。

### 2.2 拟解决的核心问题

金融学科研与教学中，师生长期面临三类痛点：

- **数据难采集**：行情、资金、板块、新闻分散在多个公开数据源，格式异构、更新频繁，人工采集耗时且易错；
- **结论难研判**：原始数据量大，缺乏统一、可解释的量化分析框架，研究结论难以溯源、难以复现；
- **工具门槛高**：传统量化工具配置复杂、面向专业交易，师生缺少一个“即问即答”且能讲清依据的科研辅助工具。

本作品通过“智能体 + 量化引擎”的组合，把海量数据转化为可解释、可复盘的研判结论，作为科研数据底座与教学实训平台，降低师生开展量化研究与成果研判的门槛。

## 三、核心技术实现说明

作品整体架构为“校级智能体平台（交互与编排）+ StockPulse 量化引擎（数据与研判）+ 大语言模型（解释与呈现）”。智能体基于校级智能体开发平台创作，通过知识库沉淀方法论，通过自定义工具调用 StockPulse 实时 API，最终由大语言模型生成人类可读的研判结论。

### 3.1 提示词设计

提示词分为三层：

**（1）系统提示词（角色与行为约束）**

明确定位智能体为“面向高校科研与教学的金融量化研究助手”，规定五类能力范围与回答规范：先调用工具获取实时数据再作答；所有结论必须引用具体数据点；区分“数据事实”与“模型研判”，概率须标注置信度；涉及涨跌方向时附“仅供科研教学参考，不构成投资建议”免责声明。该层保证智能体行为稳定、边界清晰、不越界给出投资建议。

**（2）工具调用指令（结构化取数）**

为每个工具编写精确的自然语言描述与入参 Schema（如 `get_market_sentiment`、`get_next_session_prediction` 等），使模型在意图识别后能准确选择并调用正确工具、传入正确参数。

**（3）研判生成提示词（结论呈现）**

沿用底层引擎的简报 Prompt 规范：要求用 100-150 字中文生成简洁研判摘要，必须引用至少 2 个具体数据点，不给出投资建议。通过“结构化数据 → 可读结论”的转换，让模型只负责解释已有结论、不直接预测，从而降低幻觉风险。

### 3.2 知识库搭建

知识库承载“方法论与术语”，保证智能体在术语解释与口径说明上的稳定性，共沉淀四类内容：

1. **量化术语表**：情绪分、市场宽度、涨跌停、连板梯队、赚钱效应、量能比、主力资金、风险偏好、VIX、板块资金流等定义；
2. **指标方法论**：A 股情绪 8 因子及权重、全球情绪 6 因子及权重、次日预测 6 因子规则基线、信号引擎规则；
3. **研判口径与免责**：结论引用规范、概率≠确定性、科研教学用途、不构成投资建议；
4. **常见问答 FAQ**：典型问题与标准回答，覆盖“情绪分怎么算”“预测依据是什么”“数据多久更新”等。

### 3.3 工作流逻辑

智能体运行采用五步工作流：

```
用户提问
  → ① 意图识别（判定能力域：情绪/宽度/板块/信号/预测/个股/新闻）
  → ② 工具调用（命中对应工具，请求 StockPulse 实时 API 获取结构化数据）
  → ③ 数据整合（按知识库方法论归一化、取数）
  → ④ 研判生成（大语言模型按回答规范生成结论，引用数据点、标注置信度）
  → ⑤ 输出（结论 + 数据依据 + 免责声明）
```

工具背后是 StockPulse 量化引擎，核心包括：

- **市场情绪引擎**：A 股情绪分（市场宽度 15%、涨跌停强度 15%、连板晋级率 15%、成交量能 15%、板块扩散 15%、主力资金 10%、指数趋势 8%、新闻情绪 7%）与全球情绪分（股指风险偏好 25%、VIX 反向 20%、美元强弱反向 15%、黄金避险反向 10%、原油/铜增长预期 10%、全球新闻情绪 20%），每个因子保留原始值、归一化值与权重；
- **信号引擎**：将资金、量价、新闻、公告、异动汇总为机会/风险信号，每条含标题、摘要、证据链、置信度、严重级别；
- **次日预测引擎**：规则基线（情绪 35% + 量能 20% + 全球风险 15% + 主力资金 15% + 涨跌停比 10% + 指数趋势 5%），输出涨/平/跌概率与置信度；
- **数据底座**：新浪、东方财富等公开数据源的实时行情、资金流、板块、新闻采集，结构化入库。

## 五、作品亮点与创新性总结

1. **可解释、可溯源的量化研判**：情绪因子、信号证据链、预测依据全部保留原始值与权重，每个结论都能“追到数据”，区别于只给结果的黑箱式 AI，契合科研对可复现、可验证的要求。

2. **“数据事实”与“模型研判”分离**：大语言模型只负责解释结构化结论、不直接预测，从架构上降低幻觉，保证结论有据可依。

3. **多源异构数据实时融合**：行情、资金流、板块、新闻多源采集与结构化入库，智能体通过工具实时取数，回答基于当日真实数据而非静态资料。

4. **面向学科建设，双重价值**：既是科研数据底座（支撑量化研究、成果研判），又是金融、数据科学等学科的教学实训平台（学生可对照因子与权重理解量化分析方法）。

5. **健壮与容错**：LLM 不可用时自动降级为规则模板生成，保证服务稳定；数据缺失时明确提示、不编造，符合“功能完整且运行稳定”的要求。
