## 二、作品功能简介与拟解决的核心问题

### 2.1 作品功能简介

StockPulse 是一个面向高校金融科研与教学的智能量化研究智能体。它以"多源实时采集—可解释量化建模—大模型智能研判"为主线，构建了五大核心能力矩阵：全市场情绪因子研判、市场宽度与资金流向监测、机会与风险信号识别、次日大盘概率预测以及个股深度概览。系统不仅输出研判结论，更通过可视化表格与多维度数据回溯，提供完整、可复盘的证据链。

### 2.2 拟解决的核心问题（科研痛点分析）

在高校金融学科研与实训场景中，师生长期面临三大痛点：

1. **数据获取成本高**：行情、资金流、板块轮动等多源异构数据分散在不同接口，格式不一且更新频繁，科研人员往往要耗费大量精力在数据清洗与对齐上。
2. **"黑盒式"AI 难以建立学术信任**：传统大语言模型往往直接给出主观结论，无法展示底层的计算依据和权重，这与科研要求的"可复现、可验证"背道而驰。
3. **传统量化工具门槛高**：使用传统量化框架需要较强的编程背景，而普通师生更需要"即问即答"的辅助工具。

本作品通过"智能体调度 + 量化引擎计算"的双层架构，将海量数据转化为可解释、可溯源的量化研判。这不仅是一个问答机器人，更是一个降低科研门槛的数据底座与教学实训平台。

## 三、核心技术实现说明

**图 3-1 StockPulse 系统整体架构图**

（此处插入架构图）

本作品整体架构由"校级智能体平台（前端交互）"与"StockPulse 量化引擎（后端计算）"深度耦合而成。核心实现包含以下四个维度：

### 3.1 提示词工程与边界约束（Prompt Engineering）

系统设计了多层提示词防御体系，包括：角色约束指令（限定 AI 为严谨的量化研究员）、工具调用指令（保障 API 传参的绝对精准）以及合规拦截指令。通过系统提示词的强约束，实现对"非法荐股""越界操作"的**稳定拒绝**，并强制触发免责声明。

### 3.2 金融专属 RAG 知识库搭建

为防止大模型在金融专业术语上产生"幻觉"，本作品构建了专属的 RAG（检索增强生成）知识库，沉淀了 5 份核心文档：《量化术语表》《指标方法论》（涵盖 A 股 8 因子权重与计算公式）《研判口径与免责》《常见问答 FAQ》《数据来源与边界》。当用户询问"情绪分怎么算"时，系统能通过向量检索精准命中算法公式，并交由大模型解释，确保口径统一。

### 3.3 复杂意图识别与全链路调度工作流

系统打通了完整的 Agent 工作流：用户输入 → 语义解析与意图识别 → Function Calling（自动调取 StockPulse 实时 API）→ 多源数据整合与规则引擎计算 → LLM 解释研判结论 → 前端可视化呈现。实现了从"自然语言"到"结构化数据"再到"自然语言解释"的高效闭环。

**数据来源与更新频率**：行情来自新浪（主）、腾讯（备）双源，资金流与板块来自东方财富，新闻来自新浪 7×24 与 RSS 网关。行情采集每 30 秒一轮（盘中），资金流/板块/新闻任务 15–30 秒，盘后自动降频。

### 3.4 双引擎驱动的量化核心

系统底层摆脱了对大模型预测的依赖，采用规则引擎进行严谨计算：市场情绪引擎（A 股 8 因子加权，展示原始值、归一化值与权重）、信号引擎（捕捉机会/风险信号，附置信度与严重级别）、次日预测引擎（基于规则基线输出涨/平/跌概率，并输出各因子**边际贡献**）。大模型仅负责将结构化结果转化为人类可读的研判文本，从架构上杜绝金融预测的幻觉风险。

## 五、作品亮点与创新性总结

本作品的创新性主要体现在以下三个维度：

### 5.1 架构创新：彻底解决金融 AI 的"黑盒幻觉"

区别于市面上"让大模型直接预测涨跌"的产品，本系统首创了"数据事实与模型研判分离"的架构。量化引擎负责严密的因子加权与规则计算（保障准确性），大模型仅负责解释与呈现（发挥语言优势）。同时，所有结论均可溯源至原始数据（证据链与因子表），完美契合科研学术要求的"可复现、可验证"。

### 5.2 场景适配创新：面向学科建设的"科研+教学"双引擎

针对高校痛点量身定制。对科研而言，它是提供多源异构数据融合、实时计算与信号回溯的分析底座；对教学而言，它通过"即问即答"的对话交互，极大降低了金融工程、量化投资等课程的实操门槛。

### 5.3 工程健壮与合规创新：金融级的风控与容错机制

系统内置了严密的合规边界与鲁棒性处理机制。面对非交易时段的数据缺失，系统能如实反馈快照状态而不伪造实时行情；面对越界荐股请求，能严格遵守合规要求予以拒绝。此外，当 LLM 不可用或超时时，系统可自动降级为规则模板输出，保障核心业务永远在线。
