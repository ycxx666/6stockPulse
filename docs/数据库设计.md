# 6stockPulse · 数据库设计

## ER 概览

```
┌─────────────────┐
│     stocks      │  股票基础信息
│  (维度表)        │  SH/SZ/BJ
└────────┬────────┘
         │
         ├──→ stock_prices    (时间序列, 按 trade_date 分区)
         ├──→ fund_flow       (时间序列, 资金流向)
         ├──→ stock_news      (个股新闻, UNIQUE(code, news_id))
         └──→ stock_announcements (个股公告)

┌─────────────────┐
│    sectors      │  板块基础 (行业/概念)
└────────┬────────┘
         └──→ sector_fund_flow (板块资金流, 按 trade_date 分区)

┌─────────────────┐         ┌─────────────────┐
│      news       │ ←────── │   stock_news    │
│  7×24 快讯        │  news_id │  个股新闻         │
└─────────────────┘         └─────────────────┘

┌─────────────────┐
│   crawl_log     │  爬虫审计
└─────────────────┘

latest_quotes  ◄──── DISTINCT ON stock_prices (物化视图)
latest_sector  ◄──── DISTINCT ON sector_fund_flow (物化视图)
```

## 表设计

### stocks (股票基础)
```sql
stock_code      VARCHAR(10)  PK
stock_name      VARCHAR(50)
market          ENUM('SH','SZ','BJ')
industry        VARCHAR(50)              -- 申万行业
sector_code     VARCHAR(20)              -- 板块代码
list_date       DATE
total_shares    BIGINT
circ_shares     BIGINT
is_active       BOOLEAN DEFAULT TRUE
extra           JSONB
created_at, updated_at  TIMESTAMPTZ
```

### stock_prices (行情时间序列)
- **分区策略**: `PARTITION BY RANGE (trade_date)`
- **主键**: `(trade_date, stock_code, trade_time)`
- **写入频率**: 实时 3s, 日终 1 条
- **保留期**: 90 天 (定时清理)
- **索引**: `(stock_code, trade_time DESC)`

### fund_flow (资金流向)
- **5 档资金**: main / super_large / large / mid / small
- **字段**: 净流入 (元) + 占比 (%) + 情绪标签 (bullish/bearish/neutral)
- **写入**: 1 分钟 (交易时段)

### sector_fund_flow (板块资金)
- **类型**: industry (行业) / concept (概念)
- **关联**: 通过 `sector_code` 关联 `sectors`

### news (7×24 快讯)
- **数据源**: 新浪 zhibo 接口
- **字段**: title / content / publish_time / source / url
- **分类**: macro / policy / company / global / other
- **关联**: 数组 `stocks[]` 关联个股, `keywords[]` 用于搜索
- **GIN 索引**: stocks / keywords 用于模糊搜索

### stock_news (个股新闻)
- **数据源**: 新浪个股接口
- **关联**: `news_id` 主表 + `stock_code` 关联股
- **唯一**: `(stock_code, news_id)`

### stock_announcements (个股公告)
- **数据源**: 东方财富 np-cnotice 接口
- **字段**: ann_id / title / content / publish_time / ann_type / pdf_url
- **唯一**: `(stock_code, ann_id)`
- **类型**: 临时公告 / 定期报告 / 重大事项 / ...

### crawl_log (爬虫审计)
- 每次爬虫启动 → 1 条
- 字段: crawler_name / started_at / finished_at / success / skip / fail / error / meta
- **JSONB meta**: 动态参数 (pages / 股票数 / ...)

## 性能优化

### 分区表
- `stock_prices` 按 `trade_date` 分区
- 预创建未来 7 天分区 (爬虫启动时)
- 清理旧分区: `DELETE WHERE trade_time < NOW() - INTERVAL '90 days'`

### 物化视图
- `latest_quotes`: 每只股票最新一条行情
- `latest_sector`: 每个板块最新一条资金
- 定时刷新 (5 分钟)
- 实时行情可绕过物化视图, 直接查 `latest_quotes`

### 索引策略
| 查询 | 索引 |
|------|------|
| 个股最新行情 | `(stock_code, trade_time DESC)` |
| 当日主力流入 TOP | `main_net_inflow DESC` WHERE `trade_date = CURRENT_DATE` |
| 板块排行 | `(sector_code, trade_time DESC)` |
| 模糊搜索 | `pg_trgm` GIN |

## 扩展设计

### 可选 TimescaleDB
- `stock_prices` 改为 hypertable
- 自动压缩 7 天前数据 (10x 压缩)
- 连续聚合: `daily_close`, `hourly_volume`

### 水平扩展
- 单 PG 实例: 支撑 5000 股票 × 1 年
- 分库: 按市场 (SH/SZ/BJ) 分库
- 读写分离: 实时写入主库, 查询走从库

## 数据生命周期

| 表 | 保留策略 |
|----|----------|
| `news` | 7 天 (业务需要 30 天可调整) |
| `stock_news` | 30 天 |
| `stock_announcements` | 永久 |
| `stock_prices` | 90 天 tick, 1 天聚合 |
| `fund_flow` | 90 天 |
| `sector_fund_flow` | 90 天 |
| `crawl_log` | 30 天 |
| `stocks` | 永久 (含历史) |
| `sectors` | 永久 |

## 部署模式

### 单机 (开发)
```
PostgreSQL ┐
FastAPI   ┼── localhost
WebSocket ┘
```

### 生产 (推荐)
```
                  ┌─→ FastAPI (行情服务)  ──┐
PostgreSQL 主 ──→ ├─→ FastAPI (Web API)    ─┴─→ Nginx (负载均衡)
                  └─→ APScheduler (后台任务)
```

### 高可用
- PostgreSQL: 主从 + 读写分离
- FastAPI: 多实例 (3+) + Gunicorn + Uvicorn worker
- Redis: 缓存热点 (latest_quotes)
- Prometheus + Grafana: 监控
